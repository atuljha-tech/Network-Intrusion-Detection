PRIVACY ASSURANCE

AI-NIDS operates strictly on statistical network flow metadata (5-tuples, packet counters, timing variance). No packet payloads, application data, or user credentials are ever stored, captured, or serialized.

OPERATIONAL BOUNDARY NOTICE

Machine learning outputs and anomaly scores are probabilistic threat hypotheses. Every alert requires human analyst investigation before confirmation as a verified security incident.

LOCAL EXECUTION GUARANTEE

100% offline local runtime executing on host hardware. Built entirely on free and open-source components under a $0 budget constraint. Zero cloud telemetry dependencies.
